# Ideation Phase

## Problem Statement
Traditional bookstores make it difficult for users to search books, compare prices, and purchase books online...

## Objectives
- Build an online bookstore.
- Allow users to register and log in.
- Search books.
- Add books to cart.
- Place orders.

## Proposed Solution
The project is developed using the MERN stack...

## Scope
The system supports user authentication, book browsing, shopping cart, and order management...
