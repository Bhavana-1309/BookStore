8. # Software Requirement Specification

## Purpose
The purpose of the BookStore application is to provide an online platform
where customers can browse, search, and purchase books, while administrators
can manage books, users, and orders.

## Scope
The system supports:

- User Registration
- User Login
- Book Browsing
- Book Search
- Shopping Cart
- Order Placement
- Admin Dashboard
- Book Management
- Order Management
